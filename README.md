# StatPitch Analytics

Build a modern, dark-themed Football Statistics & Analytics Web App called 'StatPitch Analytics'.

Theme: Sleek dark mode (deep navy #0a0f1d, neon green #00ff88 accents, clean white text).

Header: App title 'StatPitch Analytics', Live Matches counter, Search Bar for teams/leagues, and a 'Go Pro' upgrade button.

Hero Section: Showcase 'Match of the Day' with live probabilities, Head-to-Head win percentages, and Over/Under 2.5 goal stats.

Main Dashboard Tabs: >   1. Fixtures & Trends: Cards showing upcoming matches with key stat pills (e.g., 'Arsenal: 80% Win Rate Home', 'Over 2.5 Goals in last 5 games').

2. H2H Comparison Tool: A side-by-side team comparison card with visual progress bars for Goals Scored, Possession, Clean Sheets, and Avg Corners.

3. Value Bets / Analytics: A table highlighting matches with high statistical probability.

Include a Pricing Modal: Simple popup showing Free vs Pro Plan (Pro unlocks AI Predictions & Corner/Card Stats)."**
